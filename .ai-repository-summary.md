## Purpose

This system implements a **4-Pillar Architecture** for autonomous AI-driven task execution:

1. **The Ear** - FastAPI webhook receiver (`src/notifier_service.py`, `src/api/webhooks.py`)
2. **The State** - GitHub Issues as task queue (`src/models/`, labels + comments)
3. **The Brain** - Background polling orchestrator (`src/services/orchestrator.py`, `src/orchestrator_sentinel.py`)
4. **The Hands** - DevContainer-based LLM worker (`src/execution/shell_bridge.py`, via `scripts/devcontainer-opencode.sh`)

Unified configuration is managed via `src/config.py` with Pydantic Settings.

## Security Features

1. **HMAC-SHA256 Verification** - All webhooks validated before processing
2. **Credential Scrubbing** - `scrub_secrets()` removes sensitive data before GitHub posts
3. **Non-root Container** - Docker container runs as unprivileged user
4. **Connection Pooling** - Single HTTP client reused for efficiency

## Agent Instructions

When working on this repository:

1. **Follow the 4-Pillar Architecture** - Changes should respect component boundaries
2. **Use the Shell-Bridge** - Sentinel dispatches via `scripts/devcontainer-opencode.sh`
3. **Scrub Secrets** - Always use `scrub_secrets()` before posting to GitHub
4. **Validate Webhooks** - All webhook handlers must verify HMAC signatures
5. **Run Tests** - Execute `uv run pytest` before committing
